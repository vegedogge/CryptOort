# CryptOort
本项目是论文《[基于安全多方计算的隐私保护异构联邦学习参与方选择](https://www.jos.org.cn/jos/article/abstract/7622)》的实验代码，实现了异构环境下的隐私保护联邦学习参与方选择过程。  
This project is the experimental code of the paper "_[Privacy-preserving Participant Selection Based on Secure Multi-party Computation in Heterogeneous Federated Learning](https://www.jos.org.cn/jos/article/abstract/7622)_", which implements the privacy-preserving client selection process within heterogeneous environments.
